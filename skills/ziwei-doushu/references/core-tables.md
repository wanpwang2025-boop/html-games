## 3. 安星公式（anChart）

- 地支序：子0丑1寅2卯3辰4巳5午6未7申8酉9戌10亥11，寅 YIN=2；生時取地支序（子0…亥11）
- 命宮：`(寅＋(生月−1)−生時) mod 12`（子時歸月宮）；身宮：`(寅＋(生月−1)＋生時) mod 12`
- 驗證：四月巳時 → 命子身戌；正月子時 → 命寅身寅（課本例）。時辰不明沿用月宮
- 命宮干：五虎遁 `start=[2,4,6,8,0][年干%5]`，`月干=(start＋生月−1)%10`
- 五行局：預設命宮納音（上表）；`set-ju` 可手動覆寫（水二／木三／金四／土五／火六）供他派掌訣用
- 紫微：`q=生日÷局數取整，r=生日 mod 局數`；`r=0 → 寅＋q−1`；`r奇 → 寅＋q−r`；`r偶 → 寅＋q＋r`（商餘口訣另有「借數」版本，見「已知流派差異」）
- 天府：`(紫微＋4) mod 12`
- 紫微系逆布：紫微→天機→太陽→武曲→天同→廉貞（各逆1宮；另有「隔一」版本，見「已知流派差異」）
- 天府系順布：天府→太陰→貪狼→巨門→天相→天梁→七殺→破軍（各順1宮）
- 十二宮：命宮起逆行＝命兄弟夫妻子女財帛疾厄遷移交友官祿田宅福德父母（逆＝地支−1；另有順布流派，見「已知流派差異」）

## 6. 已知流派差異（1981-05-25 巳時標準盤比對，待確認）

- 五行局：庚子納音壁上土 → 主流土五局；該盤掌訣取木三局（子宮庚干起木三局）
- 紫微定位：木三局22日，主流商餘公式得申；該盤借數法（22÷3＝7餘1，借2×3湊24÷3＝8，偶數順行）得亥
- 紫微系：主流緊鄰逆布（−1,−2,−3,−4,−5）；該盤為隔一式（天機−1，太陽−3，武曲−4，天同−5，廉貞−6）
- 宮位方向：主流逆布（命子→兄弟亥）；該盤順布（命子→兄弟丑）
- 輔星：祿存魁鉞左右昌曲鈴空馬等多處與主流口訣不合，且廉貞在該盤出現兩次（丑、巳必有一誤），需原盤出處核對
- 亮度：太陰子廟、破軍卯旺、天府丑廟等一致；天同午（主流陷／該盤旺）、紫微亥（主流平／該盤旺）等少數相異

## 4. 輔星口訣

- 左輔：辰起正月順至生月、逆至生時；右弼：戌起正月逆至生月、順至生時
- 文昌：戌起子時逆至生時；文曲：辰起子時順至生時
- 天魁天鉞（年干）：甲戊庚→丑未、乙己→子申、丙丁→亥酉、壬癸→巳卯、辛→午寅
- 祿存（年干）：甲寅乙卯丙戊巳丁己午庚申辛酉壬亥癸子；擎羊順1、陀羅逆1
- 火星（年支＋時順行）：寅午戌起丑、申子辰起寅、巳酉丑起卯、亥卯未起酉
- 鈴星（年支＋時逆行）：寅午戌起卯、申子辰起戌、巳酉丑起未、亥卯未起丑
- 地劫：亥起子時順至生時；地空：亥起子時逆至生時
- 天馬（年支）：寅午戌→申、申子辰→寅、巳酉丑→亥、亥卯未→巳
- 長生十二神：陽男陰女順／陰男陽女逆；基宮甲戊庚申、乙己亥、丙丁壬巳、辛子、癸卯；序長生沐浴冠帶臨官帝旺衰病死墓絕胎養
- 博士十二神：隨祿存同方向；序博士力士青龍小耗將軍奏書飛廉喜神病符大耗伏兵官府

## 5. 亮度 MIAO

十四主星每支取廟旺得利平陷（全文見 ziwei.html `MIAO`）。
例：紫微「子旺丑廟寅廟卯旺辰旺巳陷午廟未得申得酉平戌旺亥平」。
解讀位階：廟＞旺＞得＞利＞平＞陷。
