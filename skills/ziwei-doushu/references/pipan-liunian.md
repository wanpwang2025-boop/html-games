# pipan-liunian（批命＋流年斷法，對應 patterns／shortJudge／daxian）

## 1. 三方四正取法

- 命三方：命宮、財帛（命＋8支）、官祿（命＋4支）；對宮：遷移（命＋6支）
- 先列三方主星集合，再看格局，不單宮論命

## 2. 格局斷語模板（命中即用）

- 殺破狼・變動開創：三方齊七殺破軍貪狼 → 一生多變動，宜動中求財異地發展
- 紫府同宮・富貴雙全：紫微天府同宮 → 穩重有格局，宜大事業
- 紫府朝垣・尊貴：紫府對拱 → 貴人多，宜公職大企業
- 昌曲・文采：三方文昌文曲 → 聰明好學，利考試寫作口才
- 左右・貴助：三方左輔右弼 → 主管貴人緣強，宜團隊
- 火鈴・爆發：三方火鈴 → 爆發力強，宜短打競技，忌衝動
- 空劫・理想：三方地空地劫 → 理想高創意強，錢財見好就收
- 羊陀・磨練：三方擎羊陀羅 → 競爭磨練多，宜武職競技反為用
- 雙祿朝垣：祿存與化祿同宮 → 財運加倍，宜守財置產
- 祿馬交馳：天馬逢化祿同宮 → 越動越發，宜外地業務
- 化忌所在宮：該宮多操心，宜逆向慢半拍，忌加碼；務必點名宮位＋化忌星
- 無格局：三方無強組合 → 以主星廟旺＋四化＋大限走勢為主

## 3. 單宮一句斷（shortJudge）

- 紫微天府：尊貴守成，宜大格局當責
- 貪狼廉貞：桃花才藝，宜人脈舞台
- 七殺破軍：開創變動，宜動宜闖
- 天機巨門：智謀口才，宜腦力嘴力
- 太陽太陰：貴富光明，宜名宜庫
- 武曲天相：執行忠誠，宜實業輔佐
- 天同天梁：福蔭溫和，宜服務長青
- 化忌：多操心宜慢宜逆向；化祿：多機會宜把握宜存
- 兜底：以三方四正合看，不單宮論

## 4. 星性速查（STAR_INFO 全文在 ziwei.html）

批命時每顆主星取三句：性格／事業／感情。
輔星取貴人（魁鉞左右科）、文書（昌曲）、財庫（祿存）、煞（羊陀火鈴空劫耗動：宜以煞為用）方向解。

## 5. 大小限流年斗君

- 大限：`from=局數＋k×10（k=0..8）`，方向陽男陰女順／陰男陽女逆，每限10年；逐限列宮位星曜＋一句斷
- 小限基宮：寅午戌→辰、申子辰→戌、巳酉丑→未、亥卯未→丑；男順女逆＋(虛歲−1)
- 流年宮＝當年地支；斗君＝流年支逆生月順生時，正月起順佈十二流月
- 體用：大限為體、流年為用；大限吉＋流年吉（祿權科）攻，大限凶＋流年忌煞守；化忌入流年命財官遷重點提醒
