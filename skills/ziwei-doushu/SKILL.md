# ziwei-doushu

## Purpose

提供可重現 `ziwei.html` 的紫微斗數引擎：同一套曆法、安星、批命、流年規則。
任何 agent 照此 skill 執行，應與網站排盤結果一致（時辰校正選項相同時）。

## When to Use This Skill

- 使用者給出生年月日時想排命盤、問命宮主星、問格局
- 使用者問批命：性格、事業、財帛、官祿、遷移、感情
- 使用者問流年：今年運勢、大限走勢、小限、流月、斗君
- 使用者問「紫微網站用什麼規則算的」時，照本文回答並指向 canonical 實作

## Canonical Implementation

- `game/ziwei.html` 為唯一 canonical 實作；本 SKILL 是其文字規格
- 線上版：https://wanpwang2025-boop.github.io/html-games/ziwei.html
- 規則流派：三合派通用口訣；分歧處一律標示，不自創安星法
- 免責：每次輸出末尾必須加「民俗命理僅供學習娛樂參考」

## Core Engine（七層，與 ziwei.html 一一對應）

1. **曆法**：`LUNAR_INFO` 1900–2100、`solarToLunar`／`lunarToSolar`；日柱錨點 1900-01-01＝甲戌（`gan=(0+off)%10, zhi=(10+off)%12`；1900-01-31 甲辰可驗）
2. **干支**：月干五虎遁（甲己起甲寅）、時干五鼠遁；農曆正月＝寅
3. **校正**：真太陽時＝(經度−120)×4分＋簡化均時差；夜子時 23:00 後預設歸次日；換年預設農曆正月初一，選配立春（2/4 為界）
4. **命盤**：命宮＝寅起正月順數生月、逆數生時；身宮＝同起順數生月再順數生時；命宮干支五虎遁；納音定五行局（水二／木三／金四／土五／火六，見 references）
5. **主星**：紫微＝生日÷局數取商餘（餘0：寅＋商−1；餘奇逆減、餘偶順加）；天府＝紫微順＋4；紫微系六星逆布、 天府系八星順布
6. **輔星四化**：左右昌曲火鈴空劫依月時、魁鉞祿羊陀馬依年干支、生年四化用中州表、長生博士依陰陽男女順逆（細表見 references）
7. **批命流年**：亮度廟旺平陷＋三方四正＋格局表＋單宮斷；大限＝局數起限陽男陰女順行每限10年、小限男女順逆、流年＝年支入宮、斗君起正月順佈流月、大限為體流年為用

## Workflow A — 排命盤

1. 收齊輸入：國曆或農曆（年／月／日／閏否）、時辰（十二支＋早晚子，或時辰不明）、性別、姓名選填、經度、夜子時選項、換年選項
2. 國曆先做真太陽時修正再轉農曆；農曆直接取年干支，月支＝寅＋(m−1)，月干五虎遁，日柱用錨點公式，時干五鼠遁
3. 閏月：前半歸本月、後半歸次月，並主動告知不確定性
4. 依第4–6層安星，輸出十二宮表：宮名／干支／主星＋亮度／輔煞／四化／長生博士／身命標記
5. 時辰不明：只排年干四化＋月系宮位，命身宮標「僅供參考」，改看大格局＋大限

## Workflow B — 批命

1. 先看三方四正：命＋財帛（命＋8）＋官祿（命＋4），對宮遷移（命＋6）
2. 再套格局（命中任一即斷，詳見 references）：
   殺破狼／紫府同宮朝垣／昌曲／左右／火鈴／空劫／羊陀／祿存＋化祿／祿馬交馳／化忌所在宮
3. 單宮不斷生死窮通：主星看廟陷、四化看引動、煞看是否「以煞為用」（武職競技改革業務反吉）
4. 輸出順序：格局 → 命宮 → 財官遷 → 其餘九宮一句斷 → 化忌提醒

## Workflow C — 流年

1. 大限表：`from=局數＋k×10`，方向＝陽男陰女順／陰男陽女逆，列 9 限宮位星曜＋一句斷
2. 小限：年支定基宮（寅午戌→辰、申子辰→戌、巳酉丑→未、亥卯未→丑），男順女逆＋(虛歲−1)
3. 流年宮＝當年地支；斗君＝流年支逆生月順生時，正月起順佈十二流月
4. 斷法：大限為體、流年為用；大限吉＋流年祿權科＝攻，大限凶＋流年忌煞＝守；化忌入流年命財官遷重點提醒

## Output Contract

- 表格欄位：宮位／干支／星曜（含亮度四化）／一句斷；流年另給大限表＋流月表
- 星名一律用正體：紫微天機太陽武曲天同廉貞、天府太陰貪狼巨門天相天梁七殺破軍、左輔右弼文昌文曲天魁天鉞祿存擎羊陀羅火星鈴星地空地劫天馬
- 不論斷生死、疾病診斷、投資保證；不編造不存在的星曜組合
- 結尾固定附：規則揭露（三合通用、火鈴空劫閏月長生各派分歧）＋娛樂參考聲明

## Limitations

- 火鈴起宮、空劫順逆、長生博士起法、閏月歸屬各派不同，本 skill 鎖定 ziwei.html 選擇，不混用他派
- 均時差為簡化版（±15分內），要求分級精度時請改用專業萬年曆
- 時辰不明或經度未知時，主動降級為「大格局＋四化＋大限」解讀
